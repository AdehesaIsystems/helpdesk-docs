Centro de Conocimiento HelpDesk Demo

Este sitio contiene información de ejemplo para validar el funcionamiento de un agente de Microsoft Copilot Studio conectado a GitHub Pages como fuente de conocimiento pública.

Información General

HelpDesk Demo es una plataforma utilizada para la gestión de incidencias, solicitudes de servicio, activos informáticos y usuarios corporativos.

Los usuarios pueden abrir incidencias, consultar el estado de sus solicitudes, solicitar equipamiento informático y acceder a documentación de soporte.

Creación de Incidencias

Para crear una incidencia se deben seguir los siguientes pasos:

  1. Acceder a la aplicación.
  2. Seleccionar Nueva Incidencia.
  3. Introducir un título.
  4. Describir el problema.
  5. Seleccionar una prioridad.
  6. Guardar el ticket.

Las prioridades disponibles son:

  • Baja
  • Media
  • Alta
  • Crítica

Gestión de Usuarios

Los administradores pueden realizar las siguientes acciones:

  • Crear usuarios.
  • Modificar usuarios.
  • Restablecer contraseñas.
  • Bloquear usuarios.
  • Desbloquear usuarios.
  • Eliminar usuarios.

Activos Informáticos

El sistema permite registrar:

  • Portátiles.
  • Monitores.
  • Teléfonos móviles.
  • Impresoras.
  • Servidores.
  • Equipos de red.

Cada activo almacena:

  • Número de serie.
  • Fabricante.
  • Modelo.
  • Usuario asignado.
  • Fecha de compra.
  • Estado.

Procedimiento de Alta de Empleado

  1. Crear usuario corporativo.
  2. Asignar licencia Microsoft 365.
  3. Configurar Outlook.
  4. Asignar portátil.
  5. Configurar VPN.
  6. Entregar credenciales.

Tiempo estimado: 30 minutos.

Procedimiento de Baja de Empleado

  1. Deshabilitar cuenta.
  2. Retirar licencias.
  3. Recuperar dispositivos.
  4. Eliminar accesos.
  5. Archivar información.

Tiempo estimado: 45 minutos.

Preguntas Frecuentes

¿Cómo abro una incidencia?

Debes acceder al sistema y pulsar el botón Nueva Incidencia.

¿Cómo veo mis tickets?

Desde el menú principal selecciona Mis Incidencias.

¿Cómo cambio la contraseña?

Utiliza el portal de autoservicio corporativo.

¿Qué hago si Outlook no funciona?

Contacta con el equipo de soporte y adjunta una captura del error.

  • Utilizar MFA.
  • Bloquear el equipo al ausentarse.
  • No abrir correos sospechosos.
  • Notificar cualquier actividad anómala.
